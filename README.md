# Exam Mock Test

Hệ thống mô phỏng thi trắc nghiệm và luyện thi trực tuyến chuyên nghiệp.

## Tính năng chính
- **Chế độ Thi Thử (Exam Mode)**: Bấm giờ đếm ngược, làm bài 40 câu ngẫu nhiên hoặc đề chọn lọc, nộp bài chấm điểm tự động.
- **Chế độ Luyện Tập (Practice Mode)**: Tự do xem lời giải, giải thích chi tiết, gắn cờ câu khó, lọc theo chủ đề.
- **Bảng Tiến Độ Học Tập (Learning Dashboard)**: Phân tích tỷ lệ đúng/sai theo từng chủ đề, nhận diện lỗ hổng kiến thức và ôn tập nhanh.
- **Đồng bộ Đa Thiết Bị (Cloud Sync)**: Kết nối P2P qua QR Code giữa Máy tính và Điện thoại mà không cần đăng nhập.
